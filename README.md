## 📊 Project Overview
This project features a comprehensive **Power BI Dashboard** designed to provide real-time insights into credit card operations. It analyzes key performance indicators (KPIs) such as revenue, interest earned, and transaction volumes, while segmenting data by customer demographics and card categories.

## 🚀 Key Insights
Based on the analysis of the 2023 financial data:
* **Total Revenue:** Generated a total revenue of **$55.3M** with **$7.8M** in interest earned.
* **Top Card Category:** The **Blue Card** is the primary revenue driver, contributing **$46M**.
* **High-Value Customers:** **Graduates** represent the highest revenue-generating education level at **$22M**.
* **Demographic Leaders:** The **40-50 age group** contributes the most to the portfolio, totaling **$14M** in revenue.
* **Growth Tracking:** The dashboard successfully monitors **Week-over-Week (WoW)** performance, identifying significant spikes like the **14.5% revenue increase** in Week 11.

## 💡 Strategic Recommendations
* **Targeted Marketing:** Focus acquisition and retention efforts on the **40-50 age segment** and **Business professionals**.
* **Digital Transformation:** Implement strategies to shift more users toward **online transactions**, which currently trail behind physical "Swipe" methods.
* **Tier Optimization:** Develop a "Silver-to-Gold" migration path to increase the average revenue per user.

## 🛠️ Technical Stack
* **Tool:** Power BI Desktop
* **Language:** DAX (Data Analysis Expressions) for custom measures and KPIs.
* **Data Modeling:** Built a relational model connecting Customer and Transaction datasets.
